# CRISPIX — estudo de identidade aprovado

O usuario aprovou o simbolo reduzido da prancheta crispix-concept.svg: C branco aberto, pequeno losango ciano e fundo grafite com cantos arredondados (grupo transform="translate(72 558)"). Esta e a direcao visual escolhida, nao o simbolo maior com hexagono.

Manter somente como estudo de identidade nesta etapa. Nao aplicar ao plugin nem gerar nova versao por esta aprovacao. Nome aprovado: CRISPIX. Prancheta SVG preservada como referencia.
