# Native interface — dynamic Live Desk

The user approved A — Live Desk and logo proposal A. MAIN now selects a Program and its independent playlist, showing muted Preview, main A and the selected extra monitor. Extra Programs remain running while the operator changes lists. One Program / one route is the default; + Add Program and Outputs add controls allocate more explicitly. Copy A playlist fills an empty list without overwriting items; display source A mirrors live playback.

The 26 current native samples include twelve full-size default boards, two compact MAIN boards and twelve multi-output boards (three Programs / five routes). Sample art, READY and meters are marked as illustrative. Real media/widget reports are retained under evidence/; QWidget::render can omit hardware surfaces and does not prove physical signals.

The approved logo is redrawn in SVG and QPainter; raster proposal boards are not embedded as UI textures. [Brand proposals and prompts](branding/proposals/2026-10-20-r1/README.md) preserve A/B/C, including the user's A selection. [Review](REVIEW.md) links native captures and scope. Earlier boards remain in archive/ and ignored package archives.

Capture: scripts/capture-boards.ps1. Use -MultiOutput -Directory <alternate folder> for the three-Program/five-route layout. --capture-size 1280x800 exports compact MAIN. Defaults remain 1600×1000 and design/boards/.
