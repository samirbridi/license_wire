# Mizin Playout — logo proposals r1

Three raster approval concepts generated with the built-in image_gen tool on 2026-10-20. No concept is applied to the native application. English product name: **MIZIN PLAYOUT**.

- [A — monogram](A-monogram.png): cyan M / forward motion. Initial design preference for its relation to the product name.
- [B — screens](B-screens.png): coral/orange coordinated screens and routing.
- [C — flow](C-flow.png): violet/aqua P and continuous media flow.

Each 1536×1024 board includes a large lockup, monochrome application and app-icon concept. These are raster explorations; vector construction, true transparent assets and ICO/app icon exports follow the user's choice. Original outputs are retained and prior artwork remains unchanged.

Full generation prompts and built-in tool provenance are in [prompts.json](prompts.json). The user selected **A — monogram** on 2026-10-20 through the approval question. The native vector construction is stored at ../../mizin-playout-symbol.svg and implemented with QPainter in brand.hpp; it is a production redraw of the approved direction, not an embedded raster board. B and C remain preserved as alternatives.
