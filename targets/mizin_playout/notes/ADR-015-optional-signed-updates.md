# Optional native updates and private NDI runtime

The application checks the isolated `https://updates.p2pmizin.dev/playout/preview/latest.json` feed eight seconds after normal packaged startup, and every four hours. It announces available versions in a dismissible banner and Settings / Updates. English and Brazilian Portuguese release notes are supplied. Checks never download or install automatically. Tests and design boards do not schedule checks.

Metadata is a bounded JSON envelope with a detached RSA-3072/SHA-256 signature. The public trust key is compiled into the app. The private key lives only in ignored `binaries/release-signing/private.pem`: it must be backed up securely, never included in Git, package source, evidence or Cloudflare uploads. Losing it requires a separately trusted bootstrap/key migration; never generate a replacement silently. This metadata signature does not replace Windows Authenticode.

Downloads use the fixed HTTPS origin, reject redirects, validate declared byte count and SHA-256, and atomically save only verified files. Cancel discards partial files. A static Win32 helper is copied outside the application directory, independently checks and locks the installer, waits for the exact parent application to exit, invokes the native installer, then restarts the same application/profile/language/show. Portable installs use the same verified installer in portable mode; no PowerShell execution or ZIP extraction is needed on the operator's machine. Shows reopen with outputs closed. Active Programs, pending takes, open display outputs, NDI/OMT senders, import scans and unapplied edits block installation. Dirty shows must be saved first.

Existing build 0035 has no updater: install the first updater-enabled package manually once. Later packages use the optional flow. Updater checks/downloads do not interrupt playback; installation requires the idle operator action.

Publishing reuses the authorized P2PMizin R2 bucket (`ezshare-updates`) and custom domain, exclusively below `playout/`. Matching Qt/FFmpeg source archives and configuration, immutable artifacts and history are uploaded and read back in full before changing the signed latest pointer. Existing immutable objects are never overwritten with different bytes. The independent P2P feed hash is checked before/after. No P2P application, Worker, DNS or root release object is modified.

The official signed NDI Windows DLL is bundled privately beside the application, with the vendor agreement, third-party notices and nearby NDI link/trademark. NDI Tools and SDK developer binaries are excluded. OMT storage follows the resolved operator profile. Both network outputs remain opt-in. Native/network/external receiver and update-install validation are separate evidence; physical AV-sync, another LAN machine, AMD and clean Windows remain distinct qualifications.
