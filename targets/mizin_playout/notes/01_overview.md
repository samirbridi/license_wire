# Product scope

Original native playout. User requirements: broad native codecs/containers, folders and OS drag/drop, NVIDIA/AMD with CPU alternative, mirrored and independent outputs, events first then continuous scheduling, remote access, English default and optional PT-BR.

This target is isolated from Azimuth research. Current implementation and unimplemented features are listed in README.md. Native layout boards are review material; media test logs are separate evidence.
